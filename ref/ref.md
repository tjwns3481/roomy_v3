MVP 핵심 기능 명세 (Feature Specification)초기 개발 범위를 **'필수 기능'**에 집중하여 런칭 속도를 높여야 합니다.A. 호스트용 (Admin/Builder)블록형 가이드 빌더 (Block Editor):노션(Notion)이나 블로그처럼 원하는 '블록'을 쌓아서 가이드를 만드는 방식.필수 블록: 텍스트, 이미지, 유튜브/동영상 링크(사용법), 지도(구글/네이버맵 연동), 와이파이 정보, 링크 버튼.템플릿 제공: '감성 숙소형', '모던 오피스형', '한옥 스테이형' 등 디자인 프리셋 3종.QR 코드 자동 생성기:가이드 발행(Publish) 즉시 고유 QR 코드 및 단축 URL 생성.출력물 디자인 제공: "와이파이 잡으려면 스캔하세요" 문구가 적힌 인쇄용 PDF 자동 생성 (Roomy 로고 워터마크 포함).대시보드:방문자 수(QR 스캔 횟수) 통계.문의 내역(AI Chat Log): 게스트가 챗봇에게 무엇을 물어봤는지 확인 (데이터 확보용).B. 게스트용 (Viewer - Mobile Web)앱 설치 없는 웹 뷰어 (PWA):카메라로 QR 찍으면 바로 브라우저(Safari/Chrome)에서 열림.와이파이 원터치 연결 (Killer Feature):화면 최상단에 [Wi-Fi 연결하기] 버튼 배치. 누르면 비밀번호 복사 혹은 자동 연결 프롬프트 실행.다국어 자동 번역:호스트가 한국어로 써도, 게스트 브라우저 설정에 따라 영어/중국어/일어 자동 번역 노출.Roomy AI 봇 (유료 기능 체험):화면 우측 하단 플로팅 버튼."보일러 어떻게 켜?" $\rightarrow$ 가이드 내 '보일러' 블록의 내용을 요약해서 답변 + 해당 위치로 스크롤 이동.3.
