feat(editor): add drag-and-drop block reordering in PhonePreview

Implements intuitive drag-and-drop functionality for reordering content blocks
in the PhonePreview component using @dnd-kit library.

Features:
- Visual drag handle appears on block hover
- Smooth animations with GPU acceleration
- Keyboard accessibility (Space + Arrow keys)
- Touch device support
- 8px activation threshold prevents accidental drags
- Floating overlay preview during drag
- Automatic order recalculation
- Integration with existing auto-save system
