# Roomy v3 - 프로젝트 메모리

## 프로젝트 개요

숙소 호스트를 위한 디지털 가이드북 서비스

## 기술 스택

- **Frontend**: Next.js 15 (App Router) + TailwindCSS
- **Backend**: Supabase (Auth + PostgreSQL + Storage)
- **AI**: Gemini 3.0 Flash
- **Deploy**: Vercel

## 핵심 기능

1. 호스트: 가이드북 에디터 (블록 기반)
2. 게스트: 모바일 뷰어 + AI 챗봇
3. 관리자: 통계 대시보드
