# Roomy(루미) - 제품 요구사항 문서 (PRD)

> 생성일: 2026-02-01
> 버전: 1.0 (MVP)

---

## MVP 캡슐 (10줄 요약)

1. **목표**: 숙소 호스트가 3분 만에 모바일 가이드를 만들고, 게스트가 QR 스캔으로 바로 이용하는 서비스
2. **페르소나**: 에어비앤비/펜션 운영 호스트 (종이 안내서에 지친 사람)
3. **핵심 기능**: 블록 에디터, QR 생성, AI 챗봇
4. **성공 지표 (노스스타)**: 월 활성 가이드 수 (Monthly Active Guides)
5. **입력 지표**: 가이드 생성 완료율, 게스트 QR 스캔 수
6. **비기능 요구**: 게스트 페이지 LCP < 1.5초
7. **Out-of-scope**: 결제 시스템, 다국어 번역, PMS 연동 (MVP 이후)
8. **Top 리스크**: 호스트가 에디터 사용을 어려워할 수 있음
9. **완화/실험**: 미리캔버스 스타일 + 튜토리얼 온보딩
10. **다음 단계**: 화면 명세 작성 (/screen-spec)

## 1. 서비스 개요

### 1.1 슬로건
> "종이 안내서는 그만. 3분 만에 만드는 AI 모바일 숙소 가이드, Roomy."

### 1.2 핵심 가치 제안

| 대상 | 핵심 경험 |
|------|----------|
| **호스트** | 블로그 쓰듯 쉬운 제작 + 문의 전화 0통에 도전 |
| **게스트** | 앱 설치 없음 + QR 스캔 1초 후 Wi-Fi 연결 + 궁금한 건 AI에게 |

### 1.3 타겟 사용자

**1차 타겟: 펜션/에어비앤비 호스트**
- 에어비앤비, 독채 펜션, 풀빌라 운영자
- 종이 안내서를 매번 코팅하거나 출력하는 것에 지친 사람
- 반복되는 게스트 문의(Wi-Fi, 체크아웃 등)에 시간을 뺏기는 사람

## 2. 핵심 기능

### 2.1 호스트 기능

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| **블록 에디터** | 미리캔버스 스타일로 블록을 추가/편집 | MVP 필수 |
| **QR 코드 생성** | 가이드 발행 시 자동 QR + 인쇄용 PDF | MVP 필수 |
| **대시보드** | 가이드 목록, 방문자 통계, AI 문의 내역 | MVP 필수 |
| **템플릿** | 펜션/에어비앤비 기본 템플릿 1종 | MVP 필수 |
| **스토리 업로드** | 호스트 영상/사진을 스토리로 업로드 | MVP 필수 |

### 2.2 게스트 기능

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| **스토리 뷰어** | 인스타 스토리 형태로 호스트 콘텐츠 보기 | MVP 필수 |
| **메인 화면** | 메뉴 아이콘으로 Wi-Fi, 이용수칙 등 접근 | MVP 필수 |
| **Wi-Fi 연결** | 원터치 연결 또는 비밀번호 복사 | MVP 필수 |
| **AI 챗봇** | FAQ + 직접 질문 → AI 답변 | MVP 필수 |

### 2.3 관리자 기능

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| **사용자 관리** | 전체 호스트 목록, 권한 관리 | MVP 필수 |
| **가이드 관리** | 전체 가이드 보기, 삭제 | MVP 필수 |
| **서비스 통계** | 총 사용자, 총 가이드, 트래픽 | MVP 필수 |
| **AI 로그** | AI 챗봇 사용 내역 확인 | MVP 필수 |

## 3. 사용자 시나리오

### 3.1 호스트 시나리오

```
1. Roomy 가입 → 온보딩 튜토리얼
2. 대시보드에서 "+ 새 가이드" 클릭
3. 템플릿 선택 (펜션/에어비앤비)
4. 에디터에서 블록 편집 (Wi-Fi, 이용수칙, 기기사용법 등)
5. 스토리용 영상/사진 업로드
6. 저장 → QR 코드 다운로드
7. QR 스티커를 TV 옆에 부착
8. 대시보드에서 통계 확인
```

### 3.2 게스트 시나리오

```
1. 숙소 도착 → TV 옆 QR 스캔
2. 상단 스토리 서클 → 호스트 인사 영상 (선택)
3. 메뉴에서 Wi-Fi 클릭 → 원터치 연결
4. 필요시 AI 챗봇에 질문 ("보일러 어떻게 켜요?")
5. FAQ에서 선택 또는 직접 입력 → AI 답변
```

## 5. Out of Scope (MVP 제외)

- 결제/구독 시스템
- 다국어 자동 번역
- PMS 연동 (야놀자, 여기어때 등)
- 글램핑/웨딩 템플릿
- 호스트 커스텀 브랜딩 (색상/폰트)

## 6. 성공 지표

### 6.1 핵심 지표 (North Star)

**월 활성 가이드 수 (Monthly Active Guides)**
- 한 달에 1회 이상 게스트 접속이 있는 가이드 수
- 목표: 런칭 3개월 내 100개

### 6.2 입력 지표

| 지표 | 설명 | 목표 |
|------|------|------|
| 가이드 생성 완료율 | 가입 → 가이드 완성까지 | 60% 이상 |
| 게스트 QR 스캔 수 | 월 평균 스캔 | 가이드당 10회 |
| AI 챗봇 활용률 | 게스트 중 AI 사용 비율 | 30% 이상 |

## 7. 리스크 및 대응

| 리스크 | 대응 방안 |
|--------|----------|
| 호스트가 에디터 어려워함 | 미리캔버스 스타일 + 튜토리얼 온보딩 |
| AI가 잘못된 답변 | RAG로 가이드 내용만 답변 + 호스트 연락처 노출 |
| 게스트가 스토리 안 봄 | 스토리는 선택, 메인 메뉴로 바로 접근 가능 |
