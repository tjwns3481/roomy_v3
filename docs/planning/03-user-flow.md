# Roomy(루미) - 사용자 흐름도 (User Flow)

> 생성일: 2026-02-01
> 버전: 1.0 (MVP)

---

## 1. 호스트 플로우

### 1.1 회원가입 → 첫 가이드 생성

```
┌─────────────────────────────────────────────────────────────────┐
│                         회원가입 플로우                          │
└─────────────────────────────────────────────────────────────────┘

  랜딩 페이지
       │
       ▼
  [회원가입 버튼]
       │
       ▼
  ┌─────────────┐
  │ 회원가입 폼  │  이메일, 비밀번호
  └─────────────┘
       │
       ▼
  ┌─────────────┐
  │  온보딩     │  서비스 소개 튜토리얼 (3-4 슬라이드)
  └─────────────┘
       │
       ▼
  ┌─────────────┐
  │  대시보드   │  빈 상태 + "첫 가이드 만들기" CTA
  └─────────────┘
```

### 1.2 가이드 생성 플로우

```
┌─────────────────────────────────────────────────────────────────┐
│                         가이드 생성 플로우                        │
└─────────────────────────────────────────────────────────────────┘

  대시보드
       │
       ▼
  [+ 새 가이드 버튼]
       │
       ▼
  ┌─────────────┐
  │ 템플릿 선택  │  펜션/에어비앤비 템플릿 (MVP: 1종)
  └─────────────┘
       │
       ▼
  ┌─────────────────────────────────────────────┐
  │              에디터 화면                     │
  │  ┌─────────────────────────────────────┐   │
  │  │         미리보기 캔버스              │   │
  │  │  (미리캔버스 스타일)                 │   │
  │  │                                     │   │
  │  │  - 블록 추가/수정/삭제              │   │
  │  │  - 블록 순서 변경 (드래그)          │   │
  │  │  - 스토리 업로드                    │   │
  │  │                                     │   │
  │  └─────────────────────────────────────┘   │
  │                                             │
  │  [저장] [미리보기] [QR 다운로드]            │
  └─────────────────────────────────────────────┘
       │
       ├──── [저장] ────▶ 저장 완료 토스트
       │
       ├──── [미리보기] ──▶ 게스트 뷰어 미리보기 (새 탭)
       │
       └──── [QR 다운로드] ──▶ QR 코드 이미지 다운로드
                              └──▶ 인쇄용 PDF 옵션
```

### 1.3 대시보드 메인 플로우

```
┌─────────────────────────────────────────────────────────────────┐
│                         대시보드 플로우                          │
└─────────────────────────────────────────────────────────────────┘

  대시보드
       │
       ├──── [가이드 카드 클릭] ──▶ 에디터 화면
       │
       ├──── [통계 보기] ──▶ 방문자 통계
       │          │
       │          └──── QR 스캔 수
       │          └──── 페이지 조회수
       │          └──── AI 질문 수
       │
       ├──── [AI 문의 내역] ──▶ AI 대화 로그
       │          │
       │          └──── 날짜별 질문/답변 목록
       │          └──── 자주 묻는 질문 분석
       │
       └──── [+ 새 가이드] ──▶ 템플릿 선택
```

## 2. 게스트 플로우

### 2.1 QR 스캔 → 가이드 열람

```
┌─────────────────────────────────────────────────────────────────┐
│                         게스트 메인 플로우                        │
└─────────────────────────────────────────────────────────────────┘

  숙소 도착
       │
       ▼
  QR 코드 스캔 (TV 옆 스티커)
       │
       ▼
  ┌───────────────────────────────────────────────────────────────┐
  │                    게스트 메인 화면                            │
  │  ┌─────────────────────────────────────────────────────────┐ │
  │  │  [○] [○] [○]  ← 스토리 서클 (인스타 스타일)              │ │
  │  │                  호스트가 올린 영상/사진                  │ │
  │  └─────────────────────────────────────────────────────────┘ │
  │                                                               │
  │  ┌─────────────────────────────────────────────────────────┐ │
  │  │              숙소 메인 사진                              │ │
  │  └─────────────────────────────────────────────────────────┘ │
  │                                                               │
  │  ┌─────┐ ┌─────┐ ┌─────┐ ┌─────┐                            │
  │  │Wi-Fi│ │수칙 │ │기기 │ │맛집 │  ← 메뉴 아이콘              │
  │  └─────┘ └─────┘ └─────┘ └─────┘                            │
  │                                                               │
  │                              [🤖 AI 챗봇]  ← 플로팅 버튼      │
  └───────────────────────────────────────────────────────────────┘
```

### 2.2 스토리 보기 플로우

```
┌─────────────────────────────────────────────────────────────────┐
│                         스토리 플로우                            │
└─────────────────────────────────────────────────────────────────┘

  메인 화면 > 스토리 서클 클릭
       │
       ▼
  ┌─────────────────────────────────────────────────────────────┐
  │                     스토리 뷰어                              │
  │                                                              │
  │  ┌──────────────────────────────────────────────────────┐   │
  │  │                                                      │   │
  │  │              전체 화면 스토리                         │   │
  │  │              (영상 또는 이미지)                       │   │
  │  │                                                      │   │
  │  │  ─────────────────────────────────────────────────   │   │
  │  │  [■■■□□□□]  ← 진행 바                                │   │
  │  │                                                      │   │
  │  └──────────────────────────────────────────────────────┘   │
  │                                                              │
  │  좌측 탭: 이전 스토리  |  우측 탭: 다음 스토리               │
  │  아래 스와이프: 스토리 종료 → 메인 화면                      │
  └─────────────────────────────────────────────────────────────┘
```

### 2.3 메뉴 상세 플로우

```
┌─────────────────────────────────────────────────────────────────┐
│                         메뉴 상세 플로우                         │
└─────────────────────────────────────────────────────────────────┘

  메인 화면
       │
       ├──── [Wi-Fi] ──▶ Wi-Fi 상세
       │                   │
       │                   └── SSID 표시
       │                   └── 비밀번호 (마스킹 + 복사 버튼)
       │                   └── [원터치 연결] 버튼
       │                   └── 메모 (호스트 입력)
       │
       ├──── [이용수칙] ──▶ 이용수칙 상세
       │                   │
       │                   └── 체크인/아웃 시간
       │                   └── 주의사항 목록
       │
       ├──── [기기사용] ──▶ 기기 사용법 상세
       │                   │
       │                   └── TV, 보일러, 에어컨 등
       │                   └── 각 기기별 설명 + 이미지
       │
       └──── [맛집/명소] ──▶ 주변 추천 상세
                           │
                           └── 카테고리별 목록 (맛집, 카페, 명소)
                           └── 지도 링크 (네이버/카카오맵)
```

### 2.4 AI 챗봇 플로우

```
┌─────────────────────────────────────────────────────────────────┐
│                         AI 챗봇 플로우                           │
└─────────────────────────────────────────────────────────────────┘

  메인 화면 > [🤖 AI 챗봇] 클릭
       │
       ▼
  ┌─────────────────────────────────────────────────────────────┐
  │                     AI 챗봇 화면                             │
  │                                                              │
  │  ┌──────────────────────────────────────────────────────┐   │
  │  │              자주 묻는 질문 (FAQ)                     │   │
  │  │                                                      │   │
  │  │  [보일러 어떻게 켜요?]                               │   │
  │  │  [체크아웃 시간이 언제예요?]                         │   │
  │  │  [Wi-Fi 비밀번호가 뭐예요?]                         │   │
  │  │  [주변에 편의점 있어요?]                            │   │
  │  │                                                      │   │
  │  └──────────────────────────────────────────────────────┘   │
  │                                                              │
  │  ┌──────────────────────────────────────────────────────┐   │
  │  │  [직접 질문하기...]                          [전송]  │   │
  │  └──────────────────────────────────────────────────────┘   │
  └─────────────────────────────────────────────────────────────┘
       │
       ├──── [FAQ 클릭] ──▶ AI 답변 표시
       │
       └──── [직접 입력] ──▶ AI 답변 표시
                             │
                             └── 가이드 내용 기반 답변
                             └── 정보 없으면 "호스트에게 문의" 안내
```

## 3. 관리자 플로우

### 3.1 관리자 대시보드

```
┌─────────────────────────────────────────────────────────────────┐
│                         관리자 플로우                            │
└─────────────────────────────────────────────────────────────────┘

  관리자 로그인
       │
       ▼
  ┌─────────────────────────────────────────────────────────────┐
  │                    관리자 대시보드                           │
  │                                                              │
  │  ┌──────────────────────────────────────────────────────┐   │
  │  │  서비스 통계                                          │   │
  │  │  - 총 사용자: XXX                                     │   │
  │  │  - 총 가이드: XXX                                     │   │
  │  │  - 오늘 방문: XXX                                     │   │
  │  │  - AI 질문: XXX                                       │   │
  │  └──────────────────────────────────────────────────────┘   │
  │                                                              │
  │  [사용자 관리] [가이드 관리] [AI 로그]                       │
  └─────────────────────────────────────────────────────────────┘
       │
       ├──── [사용자 관리] ──▶ 사용자 목록
       │                       │
       │                       └── 검색/필터
       │                       └── 사용자 상세 보기
       │                       └── 권한 변경
       │
       ├──── [가이드 관리] ──▶ 가이드 목록
       │                       │
       │                       └── 검색/필터
       │                       └── 가이드 상세 보기
       │                       └── 가이드 삭제
       │
       └──── [AI 로그] ──▶ AI 대화 로그
                           │
                           └── 날짜/가이드별 필터
                           └── 질문/답변 내역
                           └── 오류 로그
```

## 5. 상태 다이어그램

### 5.1 가이드 상태

```
     ┌───────────────────────────────────────────────┐
     │                                               │
     │  [생성됨] ──▶ [편집중] ──▶ [발행됨]           │
     │     │           │            │               │
     │     │           │            │               │
     │     └─────◀─────┴────◀──────┘               │
     │        (수정 시 다시 편집중으로)              │
     │                                               │
     │  [삭제됨] ◄─── 모든 상태에서 삭제 가능        │
     │                                               │
     └───────────────────────────────────────────────┘
```

### 5.2 사용자 상태

```
     [미가입] ──▶ [가입완료] ──▶ [온보딩완료] ──▶ [활성]
                                                  │
                                                  ▼
                                               [휴면]
                                                  │
                                                  ▼
                                               [탈퇴]
```
