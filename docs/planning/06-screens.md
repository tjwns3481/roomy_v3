## 1. 인증 (Auth)

### 1.1 로그인 (/login)

- **진입**: 앱 시작, 로그아웃 후
- **요소**:
  - 이메일 입력
  - 비밀번호 입력
  - 로그인 버튼
  - 소셜 로그인 (Google, Kakao)
  - "회원가입" 링크
  - "비밀번호 찾기" 링크
- **이동**:
  - 로그인 성공 → 대시보드 (호스트) / 관리자 대시보드 (관리자)
  - 회원가입 → /signup
  - 비밀번호 찾기 → /forgot-password

### 1.2 회원가입 (/signup)

- **진입**: 로그인 페이지에서 링크
- **요소**:
  - 이메일 입력
  - 비밀번호 입력 / 확인
  - 이용약관 동의
  - 가입 버튼
  - 소셜 가입 (Google, Kakao)
- **이동**:
  - 가입 성공 → 템플릿 선택

### 1.3 비밀번호 찾기 (/forgot-password)

- **진입**: 로그인 페이지에서 링크
- **요소**:
  - 이메일 입력
  - 전송 버튼
  - 확인 메시지
- **이동**:
  - 전송 완료 → 로그인 페이지

## 2. 호스트 (Host)

### 2.1 템플릿 선택 (/templates)

- **진입**: 회원가입 후, 새 가이드 생성 시
- **요소**:
  - 템플릿 카드 그리드 (MVP: 1종, 확장 대응 UI)
  - 템플릿 미리보기 썸네일
  - "이 템플릿으로 시작" 버튼
- **이동**:
  - 템플릿 선택 → 에디터 (튜토리얼 시작)

### 2.2 에디터 (/editor/:guideId)

- **진입**: 템플릿 선택 후, 대시보드에서 가이드 클릭
- **레이아웃**: 풀스크린 (미리쮤버 스타일)

#### 상단 바
| 위치 | 요소 |
|------|------|
| 왼쪽 | ← 대시보드, 가이드 제목 (클릭 수정) |
| 중앙 | 자동 저장 상태, 기기별 전환 (📱💻) |
| 오른쪽 | ⚙️ 설정/테마, 미리보기, 발행/QR |

#### 본문 영역
- **블록 추가**: 블록 사이 + 버튼 (Hover), 하단 빈 영역
- **블록 클릭**: 인라인 편집 (텍스트) + 우측 패널 (상세 옵션)
- **블록 공통**: 삭제, 순서변경(드래그), 복제 아이콘

#### 우측 패널 (블록 선택 시)
- 블록별 상세 옵션
- 텍스트: 글자 크기, 색상, 정렬
- 이미지: 업로드, 캡션
- 지도: 주소 검색, 좌표

#### MVP 블록 8종
| 카테고리 | 블록 |
|----------|------|
| 기본 정보 | 📶 Wi-Fi, 📋 이용수칙, 🏠 시설안내, 📞 연락처 |
| 콘텐츠 | 📖 스토리, 🖼️ 갤러리, 📝 텍스트 |
| 위치 | 🗺️ 지도 |

#### 튜토리얼 (첫 방문 시)
- 클릭 투어 방식 (툴팁)
- "건너뛰기" 버튼 제공
- 에디터 위에 오버레이로 표시

### 2.3 대시보드 (/dashboard)

- **진입**: 로그인 후, 에디터에서 뒤로가기
- **요소**:
  - 헤더: 로고, 계정 메뉴
  - 가이드 카드 목록 (그리드)
    - 썸네일, 제목, 발행 상태, 조회수
    - 편집/삭제/QR 버튼
  - "+ 새 가이드" 버튼
  - 빈 상태: CTA 안내
- **이동**:
  - 가이드 카드 → 에디터
  - 새 가이드 → 템플릿 선택
  - 계정 메뉴 → 설정

### 2.4 미리보기 모달

- **진입**: 에디터에서 "미리보기" 버튼
- **형태**: 모달/오버레이
- **요소**:
  - 모바일 프레임 (디바이스 목업)
  - 게스트 뷰 렌더링
  - 닫기 버튼
- **이동**:
  - 닫기 → 에디터로 복귀

### 2.5 QR 다운로드 모달

- **진입**: 에디터에서 "QR" 버튼, 대시보드에서 QR 버튼
- **형태**: 모달
- **요소**:
  - QR 코드 이미지
  - 가이드 URL
  - 다운로드 버튼 (PNG, PDF)
  - 링크 복사 버튼
- **이동**:
  - 닫기 → 이전 화면

### 2.6 계정 설정 (/settings)

- **진입**: 대시보드 계정 메뉴
- **요소**:
  - 프로필 정보 (이름, 이메일)
  - 연락처 (가이드 푸터에 표시)
  - 비밀번호 변경
  - 요금제 정보 (링크)
  - 로그아웃
- **이동**:
  - 요금제 → /pricing

### 2.7 요금제 (/pricing) - UI만 MVP

- **진입**: 계정 설정, 랜딩 페이지
- **요소**:
  - Free / Pro / Business 카드
  - 기능 비교 테이블
  - "Pro 시작하기" 버튼 → "준비 중" 모달
- **이동**:
  - 버튼 클릭 → 이메일 수집 모달

## 3. 게스트 (Guest)

### 3.1 메인 (/g/:slug)

- **진입**: QR 스캔, 링크 접속
- **레이아웃**: 모바일 퍼스트

#### 상단: 스토리 서클
- 가로 스크롤
- 서클: Welcome, Check-in, Wi-Fi 등
- 클릭 → 스토리 뷰어

#### 하단: 메뉴 아이콘 그리드
- 2-3열 그리드
- 아이콘: 🏠 숙소안내, 📶 Wi-Fi, 📋 이용규칙 등
- 클릭 → 바텀시트 (단순) / 상세페이지 (긴 콘텐츠)

#### AI 챗봇 FAB
- 하단 우측 플로팅
- 스크롤 시 나타남
- 클릭 → AI 챗봇

### 3.2 스토리 뷰어

- **진입**: 스토리 서클 클릭
- **형태**: 풀스크린 오버레이
- **요소**:
  - 이미지/영상
  - 진행 바
  - 좌우 탭 (이전/다음)
  - X 닫기
- **이동**:
  - 닫기 → 메인

### 3.3 바텀시트

- **진입**: 메뉴 아이콘 클릭 (단순 정보)
- **형태**: 하단에서 슬라이드 업
- **대상**: Wi-Fi, 체크아웃, 연락처 등
- **요소**:
  - 제목
  - 내용 (텍스트, 이미지)
  - "복사하기" 버튼 (Wi-Fi 비번 등)
- **이동**:
  - 아래로 스와이프 / 배경 클릭 → 닫기

### 3.4 상세 페이지 (/g/:slug/:blockId)

- **진입**: 메뉴 아이콘 클릭 (긴 콘텐츠)
- **대상**: 맛집 리스트, 숙소 이용규칙 상세
- **요소**:
  - 헤더 (뒤로가기, 제목)
  - 본문 콘텐츠
  - 이미지, 텍스트, 지도 등
- **이동**:
  - 뒤로가기 → 메인

### 3.5 AI 챗봇

- **진입**: FAB 클릭
- **형태**: 바텀시트 또는 풀스크린
- **요소**:
  - FAQ 버튼 리스트 (자주 묻는 질문)
  - 채팅 입력창
  - AI 응답 영역
  - 호스트 연락처 (AI 한계 시)
- **이동**:
  - 닫기 → 메인

### 3.6 에러/404 페이지

- **진입**: 잘못된 URL, 비공개 가이드
- **요소**:
  - 에러 메시지
  - 안내 텍스트
  - 홈으로 가기 (또는 없음)

## 4. 관리자 (Admin)

### 4.1 관리자 대시보드 (/admin)

- **진입**: 관리자 로그인 후
- **요소**:
  - 총 사용자 수
  - 총 가이드 수
  - 오늘 QR 스캔 수
  - 최근 가입자 목록 (5개)
- **이동**:
  - 각 섹션 → 상세 페이지

### 4.2 사용자 목록 (/admin/users)

- **진입**: 관리자 대시보드
- **요소**:
  - 테이블: 이메일, 가입일, 가이드 수, 상태
  - 검색/필터
  - 사용자 상세 보기
  - 계정 정지/삭제
- **이동**:
  - 사용자 클릭 → 상세 모달

### 4.3 가이드 목록 (/admin/guides)

- **진입**: 관리자 대시보드
- **요소**:
  - 테이블: 제목, 호스트, 발행 상태, 조회수
  - 검색/필터
  - 미리보기
  - 비공개 처리
- **이동**:
  - 가이드 클릭 → 미리보기 모달

### 4.4 AI 로그 (/admin/ai-logs)

- **진입**: 관리자 대시보드
- **요소**:
  - 테이블: 질문, 응답, 가이드, 시간
  - 검색/필터
  - 응답 품질 마킹 (정확/부정확)
- **이동**:
  - 로그 클릭 → 상세 모달

## 화면 흐름도 (User Flow)

### 호스트 플로우

```
[가입] → [템플릿 선택] → [에디터 + 튜토리얼]
                              ↓
                        [저장/발행]
                              ↓
                        [QR 다운로드]
                              ↓
[대시보드] ←───────────── [완료]
    ↓
[가이드 편집] → [에디터]
```

### 게스트 플로우

```
[QR 스캔] → [메인 화면]
                ↓
    ┌───────────┴───────────┐
    ↓                       ↓
[스토리 뷰어]          [메뉴 클릭]
    ↓                       ↓
  [닫기]           ┌────────┴────────┐
    ↓              ↓                 ↓
[메인]        [바텀시트]        [상세 페이지]
                   ↓                 ↓
               [닫기]            [뒤로]
                   ↓                 ↓
               [메인] ←───────── [메인]
                   ↓
              [AI FAB 클릭]
                   ↓
              [AI 챗봇]
```
